**Дисципліна:** Якість програмного забезпечення та тестування

**Виконав:** Даниїл Пушня, група ІПЗ-23006б

REST API для керування інвентарем книг, покупок і замовлень клієнтів.

Стек: Python, FastAPI, pytest, Postman.

## Структура проєкту
 
```
Lab_4_Pushnia/
├── app/                                  # код застосунку
│   ├── __init__.py
│   ├── bookstore.py                      # бізнес-логіка: книги, покупки, замовлення
│   ├── schemas.py                        # Pydantic-схеми запитів і відповідей
│   └── main.py                           # ендпоінти FastAPI
├── tests/                                # тести
│   ├── __init__.py
│   ├── conftest.py                       # спільні фікстури (чистий магазин для кожного тесту)
│   ├── test_bookstore.py                 # модульні тести бізнес-логіки
│   └── test_api.py                       # тести ендпоінтів API
├── postman/
│   └── Bookstore.postman_collection.json # колекція Postman
├── pytest.ini                            # налаштування pytest
├── requirements.txt                      # залежності
└── README.md
```

## Швидкий старт

**1. Встановити залежності**
```
pip install -r requirements.txt
```

**2. Запустити сервер**
```
uvicorn app.main:app --reload
```
Сервер працює на http://127.0.0.1:8000, документація API - http://127.0.0.1:8000/docs

**3. Запустити тести** (в іншому терміналі, сервер для тестів не потрібен)
```
pytest
```
Очікуваний результат: `74 passed`

**4. Перевірити в Postman** (сервер має бути запущений)

Import → `postman/Bookstore.postman_collection.json` → Run collection

## Ендпоінти

**Книги**

| Метод | Адреса | Що робить |
|-------|--------|-----------|
| POST | `/books/` | Додати книгу |
| GET | `/books/` | Усі книги |
| GET | `/books/{id}` | Книга за ID |
| GET | `/books/isbn/{isbn}` | Книга за ISBN |
| PUT | `/books/{id}` | Оновити ціну, кількість, опис |
| DELETE | `/books/{id}` | Видалити за ID |
| DELETE | `/books/isbn/{isbn}` | Видалити за ISBN |

**Замовлення**

| Метод | Адреса | Що робить |
|-------|--------|-----------|
| POST | `/orders/` | Створити замовлення (покупка) |
| GET | `/orders/` | Усі замовлення |
| GET | `/orders/{id}` | Замовлення за ID |
| PUT | `/orders/{id}/status` | Змінити статус |
| GET | `/customers/{id}/orders` | Замовлення клієнта |

Статуси замовлення: `processing` (на обробці) → `paid` (оплачено) → `shipped` (відправлено) → `completed` (виконано), а також `cancelled` (скасовано).

## Приклади запитів

Додати книгу - `POST /books/`
```json
{"isbn": "978-0-13-235088-4", "title": "Clean Code", "author": "Robert C. Martin", "price": 450, "quantity": 10}
```

Створити замовлення - `POST /orders/`
```json
{"customer_id": 1, "items": [{"book_id": 1, "quantity": 2}]}
```

Змінити статус - `PUT /orders/1/status`
```json
{"status": "shipped"}
```

## Основні правила

- ISBN унікальний (повтор → 409) і не змінюється (спроба змінити → 400).
- Видалення неіснуючої книги не є помилкою (відповідь `"deleted": false`).
- Покупка зменшує кількість книг; якщо книг недостатньо → 409.
- Дані зберігаються в пам'яті й очищуються після перезапуску сервера.
